# South Brunswick Aerospace Club

A futuristic, Palantir-inspired website for the South Brunswick Aerospace Club (SBARC).

## Tech Stack

- **Next.js 14** (App Router)
- **TypeScript**
- **Tailwind CSS**
- **Vercel-optimized** (standard Next.js deployment)

## Development

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) to view the site.

## Build & Deploy

```bash
npm run build
```

Deploy to Vercel by connecting your GitHub repo—it will auto-detect Next.js and deploy.

**If you get 404 on Vercel:** In your Vercel project → Settings → General, ensure:
- **Root Directory** is empty or `.` (not a subfolder)
- **Framework Preset** is Next.js
- **Output Directory** is empty (do not set to `out`)

## Pages

- **Home** – Hero with Apply CTA and space shuttle visual
- **About** – Mission pillars (Learn, Connect, Grow)
- **Team** – Founders and board team photo
- **Research Publications** – Liquid rocket engine research paper

## Apply Link

The Apply Now button links to the club's Google Form for new member applications.
